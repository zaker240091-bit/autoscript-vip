# 🌑 Dark World VPN - Menu Files Installer

This package contains all the menu command files for Dark World VPN script.

## Installation

```bash
tar -xzf darkworld-menus.tar.gz
cd darkworld-menus
bash install-menus.sh
```

Or if you have a zip file:

```bash
unzip darkworld-menus.zip
cd darkworld-menus
bash install-menus.sh
```

## What it installs

All 65+ menu commands including:
- `menu` - Main menu
- `addssh`, `addvless`, `addtr`, `addss` - Add users
- `cekssh`, `cekvless` - Check online users
- `bw` - Bandwidth monitor
- `speedtest` - Speed test
- `autokill`, `autoreboot` - Auto services
- `quota-reset` - Daily quota reset
- And 50+ more commands

## After installation

Run the menu:

```bash
menu
```

Or use any command directly, e.g.:

```bash
addssh          # Add SSH user
addvless        # Add VLess user
bw              # Check bandwidth
speedtest       # Run speedtest
```
